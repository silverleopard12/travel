# travel

여행 일정을 작은 웹 페이지로 만들어 둔 곳.

## 무엇인가

여행마다 한 장짜리 일정표다. 두 페이지 모두 검색엔진이 색인하지 않도록 `noindex`를 걸었고, 삿포로 페이지는 예약번호, 결제금액 같은 개인정보를 가려 두었다. 페이지는 GitHub Pages로 공개한다.
