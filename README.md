# travel

Trip itineraries as small web pages, in Korean.

## What it is

Each trip is a single-page itinerary. Both pages ask search engines not to index them (`noindex`), and the Sapporo page has personal information such as booking numbers and payment amounts redacted. The pages are published with GitHub Pages.
